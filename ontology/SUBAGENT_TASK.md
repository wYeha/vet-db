# Инструкция субагенту: смысловые аннотации глав одной книги

Ты аннотируешь ОДНУ книгу базы знаний VetAI. Читаешь текст САМ (через sqlite3/python).
**Категорически нельзя использовать внешние LLM/API (RouterAI и т.п.)** — только твои
собственные способности Claude. Работаешь строго по фактическому тексту, ничего не
выдумываешь.

## Вход
- Карта глав: `E:\Pets\vet-DB\ontology\chapters\<slug>.json` — поля:
  `source_id`, `num_pages`, `chapters` (курированные главы: `title`, `start`, `end`,
  где `start=null` — не сматчилось), `markdown_headings` (реальные `#`-заголовки с
  `page` — это якоря для выравнивания).
- Тексты: SQLite `E:\Pets\vet-DB\data\index.db` (только чтение), таблица
  `pages(source_id, page_index, markdown)`; подзаголовки — `toc(...level, page_index, origin='markdown')`.

## Что сделать
1. **Выровнять главы на страницы.** Для главы с `start`/`end` — используй их. Для
   `start=null` — найди её начало по `markdown_headings` (заголовок с близким названием;
   если между двумя якорями несколько глав — распредели по порядку их заголовков) или
   по первым страницам предполагаемого диапазона. Границы ±1–2 стр не важны.
   - Если `chapters` ПУСТОЙ (нет курированного оглавления) — бери структуру из
     `markdown_headings` (level-1). Для статейных книг (`vic_articles_*`) каждый заголовок
     ≈ статья.
2. **Аннотировать каждую главу** (2–3 строки): «**о чём** → **болезни/возбудители с
   латынью** (напр. *Streptococcus suis*, PRRSV) → **препараты/методы**». Крупные главы
   (>40 стр, напр. «Вирусные/Бактериальные болезни») НЕ читай сплошь: возьми level-2
   подзаголовки в диапазоне (`toc` markdown level=2) + первые страницы, и перечисли, какие
   конкретно болезни/возбудители разобраны. Читай эффективно (заголовки + сэмплы).
3. **Аннотация книги** (2–3 предложения): что за книга, о чём, для кого.
4. **Пропускай служебные разделы** (оглавление, содержание, «список таблиц», список
   литературы, «резюме»/summary, предметный указатель) — как навигация бесполезны.
5. **Само-QA:** для каждого упомянутого латинского названия/термина проверь, что он реально
   есть в тексте книги — регистронезависимо В PYTHON (`term.lower() in page_md.lower()`),
   НЕ через SQL `lower()` (он не приводит кириллицу к нижнему регистру). Термин не найден в
   тексте → УБЕРИ его или помети `[?]` (не выдумывай).

## Выход
Записать файл `E:\Pets\vet-DB\ontology\annotations\<slug>.md`:
```
## Книга
<2–3 предложения>

## Главы
### <название главы> (стр A–B)
<2–3 строки: о чём + болезни/возбудители с латынью + препараты/методы>
...
```
Пиши по-русски, латинские названия сохраняй курсивом.

## В финальном ответе (кратко, 3–5 строк)
- сколько глав аннотировано, сколько пропущено служебных;
- результат само-QA (все ли термины подтвердились в тексте, были ли `[?]`);
- насколько карта глав легла на текст (были ли главы, где пришлось выравнивать вручную).
