# VetDB — навык поиска источников

База знаний VetAI — это книги (OCR-страницы в markdown), справочник препаратов и
диагностика болезней, доступные через REST API (SPEC §4). Навык — тонкая обёртка
над этими эндпоинтами. Аутентификации нет (внутренний инструмент).

Базовый URL API берётся из переменной окружения `VETDB_API_BASE`
(например `http://localhost:8011`). Все ответы — JSON.

## Как работать

1. Сформулируй ключевые слова из запроса пользователя.
2. Вызови `search` — получишь хиты с источником и номером страницы.
3. При необходимости уточни: `toc` (оглавление книги), `page` (текст страницы),
   `preparations`/`diseases` (карточки).
4. В ответе ссылайся ТОЛЬКО на реально найденное: «Источник → стр. N».
   Ничего не выдумывай.

Нумерация страниц в API — `page_index`, 0-based. Для человека показывай `N+1`.

## Инструменты (эндпоинты §4)

### search — полнотекстовый поиск
`GET /api/search`
- `q` (обязательно) — запрос (ключевые слова).
- `scope` — `all` | `books` | `pharma` | `diseases` (по умолчанию `all`).
- `source_id` — ограничить поиск одной книгой (для `books`).
- `mode` — только `keyword` (по умолчанию). **`semantic` и `hybrid` пока НЕ
  реализованы** (вернут 501) — не используй их.
- `limit` — 1..100 (по умолчанию 20).

Ответ — массив хитов:
`{ type: "page"|"preparation"|"disease", source_id, source_title, page_index,
   ref_id, title, snippet, score }`.
Для `page` веди в книгу `source_id`/`page_index`; для `preparation`/`disease` —
в карточку по `ref_id`. `snippet` содержит `<mark>…</mark>` вокруг совпадений.

### sources — список источников
`GET /api/sources` — все книги; `q` — фильтр по названию (подстрока).
Ответ: `{ id, slug, title, num_pages, has_pdf, source_url }`.
`GET /api/sources/{id}` — карточка книги (+ `pdf_url`, `description`).

### toc — оглавление книги
`GET /api/sources/{id}/toc` — `[{ title, level, page_index }]`.

### page — текст страницы
`GET /api/sources/{id}/pages/{index}` — `{ source_id, page_index, markdown,
num_pages }`. `index` — 0-based `page_index`.

### preparations — препараты
`GET /api/preparations` — фильтры: `q` (FTS по названию/инструкции),
`drug_class`, `animal`, `origin`, `limit`, `offset`.
`GET /api/preparations/{id}` — карточка (включая `instruction_md`).

### diseases — болезни
`GET /api/diseases` — `species` (фильтр). `GET /api/diseases/{id}` — карточка
со структурой `data`.

## Ограничения

- Поиск — только keyword (FTS5). Семантика/вектор (`mode=semantic|hybrid`) пока
  не реализованы.
- Классификация `species`/`kind` у источников (книг) удалена заказчиком — не жди
  этих полей в ответах по источникам.
- Инструмент не даёт медицинских рекомендаций — он находит и цитирует источники.
